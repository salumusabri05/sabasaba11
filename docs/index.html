MAKISATU — Technical System Documentation

FastAPI + MediaPipe + Keras

1. System Overview

MAKISATU (Bridging Silence) is a low-latency machine learning backend server for real-time Tanzanian Sign Language (TSL) recognition. It ingests compressed video streams via WebSockets or landmark feature sequences via REST, normalizes spatial orientation, processes temporal sequences using MediaPipe Holistic, and classifies gestures into Swahili words.

Component Specification Description
Framework FastAPI (Python 3.10) Asynchronous web application framework running on Uvicorn.
Inference Engine Keras 3 (JAX CPU Backend) Lightweight CPU execution backend avoiding GPU hardware lock-in.
Vision Pipeline MediaPipe Holistic v0.10.14 Extracts 141 normalized 3D coordinate landmarks per frame.
Audio Synthesis Azure Speech SDK Synthesizes Swahili speech (`sw-KE-ZuriNeural`) for translated sentences.
Process Manager PM2 (`makisatu-api`) Manages backend process lifecycle on VPS port `5004`.

2. Feature Pipeline Specification

Every video frame is transformed into a 141-dimensional floating-point vector representing normalized 3D spatial landmarks $(x, y, z)$.

Vector Index Layout (Total Size: 141 Floats)
Segment Index Range Float Count Landmarks Covered
Pose Landmarks [0 : 15] 15 floats 5 key points: Nose (0), Left Shoulder (11), Right Shoulder (12), Left Elbow (13), Right Elbow (14)
Left Hand Landmarks [15 : 78] 63 floats 21 3D points $(x, y, z)$ for wrist, thumb, index, middle, ring, pinky joints
Right Hand Landmarks [78 : 141] 63 floats 21 3D points $(x, y, z)$ for wrist, thumb, index, middle, ring, pinky joints

3. Frame Preprocessing & Spatial Normalization

To maintain camera-agnostic accuracy across varying mobile devices, the class FramePreprocessor in pipeline.py performs three deterministic corrections:

  1. Rotation Correction: Rotates incoming OpenCV frames by $0^\circ, 90^\circ, 180^\circ,$ or $270^\circ$ depending on client camera sensor orientation.
  2. Mirror Adjustment: Applies horizontal flip for front-facing user cameras to preserve natural UX spatial alignment.
  3. Aspect Ratio Normalization: Pads non-standard client resolutions to a strict $4:3$ landscape aspect ratio with border padding before passing to MediaPipe.
  4. Body-Relative Coordinate Scaling: Centers landmarks relative to the midpoint of the shoulders and divides all coordinates by the shoulder distance $\text{dist}(\text{shoulder}_{\text{left}}, \text{shoulder}_{\text{right}})$.

4. WebSocket API Protocol (`/ws`)

The client establishes a persistent connection to wss://model.bridgingsilence.org/ws. Client sends JSON frames or control commands at **10 FPS (100ms interval)**.

A. Client → Server: Frame Streaming Payload

{
  "type": "frame",
  "frame": "data:image/jpeg;base64,/9j/4AAQSkZJRgABAQAAAQABAAD...",
  "threshold": 0.70,
  "camera": {
    "facing": "user",
    "rotation": 270,
    "mirrored": true,
    "width": 640,
    "height": 480
  }
}

B. Client → Server: Control Commands Payload

{
  "type": "command",
  "command": "clear" // Supported: "clear", "delete_word", "delete_letter", "speak"
}

C. Server → Client: Prediction Response Payload

{
  "type": "prediction",
  "letter": "HABARI",
  "confidence": 0.9412,
  "hand_detected": true,
  "word": "HABARI",
  "sentence": "HABARI YAKO",
  "timestamp": 1723145690.12
}

D. Server → Client: TTS Audio Response Payload (Command: "speak")

{
  "type": "speak",
  "text": "HABARI YAKO",
  "audio": "UklGRiQAAABXQVZFZm10I..." // Base64 encoded WAV audio bytes
}

5. REST API Reference

POST /predict

Evaluates raw 141-float feature vectors or sequence objects directly without Base64 image encoding overhead.

Request Body Schema
{
  "features": [
    [0.12, 0.45, -0.1, ... 141 floats ...],
    [0.14, 0.44, -0.1, ... 141 floats ...]
  ],
  "threshold": 0.70
}
Success Response (200 OK)
{
  "prediction": "ASUBUHI",
  "probability": 0.9654,
  "top_predictions": [
    { "word": "ASUBUHI", "probability": 0.9654 },
    { "word": "HABARI", "probability": 0.0210 },
    { "word": "SHIKAMOO", "probability": 0.0085 }
  ],
  "sequence_length": 45
}

6. Machine Learning Model Specifications

Attribute Specification
Model File model/tsl_word_model_11.h5
Input Tensor Shape (BatchSize, 90, 141) — 90 temporal frames of 141 features
Output Layer 11-class Softmax probability distribution
Vocabulary Classes ALAMA, ASUBUHI, HABARI, JINA, JIONI, KUJITAMBULISHA, LANGU, LUGHA, MCHANA, SHIKAMOO, YAKO
Sequence Standardizer Temporal linear sampling for long sequences (>90), zero padding for short sequences (<90).
